# Central de Atendimento Inteligente

## Objetivo

Projeto de portfólio desenvolvido para praticar desenvolvimento web com React, TypeScript, Node.js e API REST.

A proposta é simular uma central de atendimento com chatbot simples, painel de chamados e integração entre front-end e back-end, aproximando conceitos estudados em programação, engenharia de software, interação humano-computador e desenvolvimento web.

## Tecnologias previstas

### Front-end
- React
- TypeScript
- Vite
- CSS
- React Router

### Back-end
- Node.js
- Express
- TypeScript

## Funcionalidades planejadas

- Página inicial do sistema
- Listagem de atendimentos/chamados
- Criação de chamados
- Alteração de status
- Chatbot simples baseado em regras
- Dashboard com métricas
- Integração entre front-end e API
- Layout responsivo
- Documentação do projeto

# Como executar

## API
```bash
cd api
npm install
npm run dev
```

A API ficará disponível em:

```link
http://localhost:3001
```


## Front-end

```bash
cd web
npm install
npm run dev
```

O front-end ficará disponível em:

```link
http://localhost:5173
```
